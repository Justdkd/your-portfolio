# 图片与视频

## 图片

把决定公开的照片放在 `public/assets/media/`。模板路径通常是 `../assets/media/name.webp`。使用短小英文文件名；同名素材重做后可换文件名避免缓存旧版本。

建议图片宽度约 1200–1600px，采用 WebP/JPG 等常见格式。模板只有几何 SVG 演示图，没有真实人物照片。原图可以保留在被 Git 忽略的 `inputs/`；发布前去除 GPS 和不需要的设备信息。

不需要制作多档照片才能使用模板。为每张照片写清楚 alt；caption 是可选展示说明。图片缺失时显示可理解的占位，但应在发布前用校验工具修好路径。

## 旅行或作品视频

可选字段：

```yaml
video: "../assets/media/porto.mp4"
cover: "../assets/media/porto-cover.webp"
hls: "../assets/media/porto/index.m3u8" # 可选
```

推荐 MP4 使用 H.264/AAC 和 faststart；封面有利于加载前展示。HLS 的播放清单与片段必须一起发布，片段路径以清单为准。模板先提供 HLS source，再提供 MP4；浏览器自行选择支持的来源，没有额外播放库。

是否可播放取决于浏览器编码支持和托管响应。部分环境需要 MP4 的 Range 请求，支持 HLS 的浏览器可采用 HLS。应检查真实手机和已发布地址；当前示例不含视频，自动测试不证明你的视频已能播放。

## 分享图

分享图使用 PNG 或 JPG 等平台接受的格式，建议 1200×630。不要用演示 SVG 当成通用社交分享图。`site.shareImage` 指向本地文件，`site.url` 填真实发布地址后，静态分享标签才包含绝对图片地址。

## 公开边界

所有放进发布目录的文件都可能被下载。不要仅在页面上隐藏私人字段；从发布内容中删掉才有效。选素材时避开不想公开的人物、证件和住址细节。

# 我的主页资料清单

复制这份清单，用自然语言填好。没有的项目写“暂时没有”，不需要为了填满模板编内容。只写愿意公开的资料。

## 我想做什么

- 模板：旅行者 / 创作者。
- 主页希望别人看完记住什么：
- 中文、英文还是双语：
- 希望保留哪些模块，按什么顺序：

## 我是谁

- 显示名字或昵称：
- 一句话介绍：
- 关于我（几句话即可）：
- 可选头像文件名：
- 可选的公开事实（例如创作方向、喜欢的旅行节奏）：

## 旅行记录（可以复制多份）

- 这次旅行的名字：
- 时间，YYYY-MM：
- 到过哪些城市，按先后顺序：
- 地图起点用哪个城市（可用大概城市，不需要具体地址）：
- 想留下的几句话：
- 照片文件名和说明：
- 可选视频和封面文件名：
- 已经去过，还是计划中：

经纬度不清楚可以让 AI 查证城市坐标，再核对地图；不要填写家庭地址。未确定的日期标为待确认，不能由 AI 编一个。

## 作品（可以复制多份）

- 作品名称、年份：
- 类别：视频 / 设计 / 文章 / 摄影 / 产品 / 其他。
- 一句话概括：
- 背景、你做了什么、结果是什么：
- 封面、更多图片或视频文件名：
- 可选项目链接：

## 经历与近况

- 想展示的经历及时间：
- 最近在做什么：

## 联系

- 公开邮箱（可留空）：
- 想展示的平台或项目链接（可留空）：

## 发布

- 已有网址或托管：
- 希望 AI 帮你完成的步骤：内容、改代码、预览、发布指导。
- 不希望公开的内容类别：

完成后，把清单与模板文件一起交给 AI，再粘贴 `prompts/use-template.md`。不要在清单中填写密码、token 或证件信息。

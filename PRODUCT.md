# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain HTML, CSS and JavaScript, with a locally bundled YAML parser. No build step, backend, npm installation or CDN is required to run the site.

## Users

People who want a personal website to keep travel memories or present creative work. They may edit content directly or ask an AI assistant to help from a plain-language worksheet.

## Product Purpose

Two complete, reusable templates: Traveler and Creator. A successful user replaces example content, previews the site, publishes it and keeps adding records.

## Capabilities and Constraints

Interactive globe, travel timeline, media details, project portfolio, experience timeline, optional sections and configurable order. Chinese/English content. Keyboard and touch interaction, responsive layout and reduced motion. All sample identities and stories are explicitly fictional. No original family material, sports theme, voice or personal decorative assets.

## Operating Context

Content YAML drives each template. A local HTTP server is required for preview. Optional Node tools validate data and produce a selected-template publishing folder. AI assistance and hosting are user-controlled and do not run as a service in this project.

## Product Principles

- Useful completed interactions, rather than a sparse starter page.
- A readable editing interface and clear instructions.
- A clean code history and public-safe sample assets.
- Reusable sections without imposing someone's personal interests.

## Evidence on Hand

Source code, geometric sample artwork, fictional records and automated checks. No real customer results, real personal photos or testimonials.
